# 论文模板提炼与复用约定

- 基准文件：`研究生数学建模word模板.docx`
- SHA-256：`643196c1574885bf5f00be17dff88573fed5eed655362b0a996c78be0cf4fdb4`
- 用途：作为本次数学建模论文 Word 成品的版式与样式基准。

## 页面与分节

- 纸张：A4 纵向。
- 封面节：左右边距约 2.21 cm，上边距约 2.97 cm，下边距约 2.34 cm；首页不同。
- 正文节：左右边距约 2.21 cm，上下边距约 4.22 cm；页脚含页码域。
- 成品沿用模板的两节结构、页眉页脚关系、主题、字体映射、编号定义和样式集合。

## 内容槽位

- 封面题目：替换为“通用神经网络处理器下的多核调度优化模型”。
- 学校、队号、队员：模板中的示例值不得沿用，统一置为“待填写”。
- 摘要与关键词：重写为本题摘要。
- 目录：生成手工目录页并保留清晰层级；打开 Word 后可按需更新为自动目录。
- 正文：按“问题重述—假设与符号—问题分析—模型建立—算法设计—实验设计—结果分析—稳健性—评价—结论”组织。
- 参考文献与附录：放在正文末尾；附录给出复现实验说明、代表性明细及绘图脚本索引。

## 样式规则

- 一级标题使用模板 Heading 1，二级标题使用 Heading 2，三级标题使用 Heading 3。
- 中文正文使用模板正文样式，英文与数字使用 Times New Roman；正文两端对齐、首行缩进。
- 表格使用细线三线式风格，表题置于表上方；图题置于图下方。
- 公式居中并编号；变量首次出现时在符号表中解释。
- 不继承模板原论文的学校、作者、图表、正文和参考文献内容。

## 复用边界

- 必须保留：模板的样式库、主题、节属性、页面尺寸、页边距、页眉页脚和页码设置。
- 可以替换：全部正文、封面字段、图表、表格与引用。
- 允许新增：本题结果图、统计表、算法伪代码、附录和实验复现说明。

## 验证策略

- 已完成 OOXML 结构审计：2 个节、A4 页面、标题样式与页码域均存在。
- 当前 Windows 运行时未检测到 LibreOffice、Microsoft Word、WPS 或 OnlyOffice，模板无法在本机转换为 PDF/PNG；因此先执行 OOXML 级校验、关系完整性检查、表格/图片边界检查和 DOCX 重开检查。
- 若用户环境安装 Word，打开成品后更新目录并检查分页即可；文档正文不依赖外部链接或宏。
